Smart Home Automation System Using AI

Project Overview

This project is a documentation-only Software Engineering course project focused on the conceptual design of an AI-based Smart Home Automation System. It describes the proposed system, its requirements, intended features, and overall design.

Project Objectives

* Identify the functional and non-functional requirements of the proposed system.
* Describe the main features and intended functionality.
* Outline the conceptual design of the smart home automation solution.
* Explore how AI could potentially improve home convenience and energy efficiency.

Project Scope

The project focuses exclusively on software engineering documentation, requirements analysis, and system design.

Note: This repository contains documentation only. No source code was written, no AI models were developed, and no functional system was implemented.
